# 02 — Cheetah3D 8.1.3 JavaScript API reference

Confidence tags: **[DOC]** bundled 8.1.3 manual · **[EX]** bundled example script · **[STR]** appears in binary strings/symbols · **[WS]** worked in prior probe scripts (`~/Documents/user_project_dir/`, copies in `research/raw/`) · **[FORUM]** forum / c3d-scripting-kb · **[INF]** inference, **must be probed in Phase 0**.

Primary local source: `/Applications/Cheetah3D.app/Contents/Resources/en.lproj/Cheetah3Dmanual/Scripting/` (`ExecuteScript.html`, `Classes/*.html`). Engine: system **JavaScriptCore** via `MWM.framework` (`MWMJSAPI.M`); bare `JSGlobalContextCreate` context — no browser globals, no timers.

## 1. Script types and lifecycle
User folders: `~/Library/Application Support/Cheetah3D/Scripts/<Type>/`; bundled: `.../Cheetah3D.app/Contents/Resources/PlugIns/Scripts/<Type>/`. The **folder decides the type**. Only `.js` files listed; subfolders OK; other top-level folders (e.g. `Scripts/Library/`) ignored by menus. Menu: **Tools › Script › {Macro, Tool, Polygon, Spline, Particle, Tag} Script › file.js**; plus "Update Menu" item (`ScriptMenuUpdate`) [STR]. The manual says *restart* after adding scripts [DOC]; whether Update Menu suffices is **[INF] — probe**. Edits to existing scripts are picked up on next run [FORUM]. Scenes reference script objects/tags by file name.

| Type | Hooks | Notes |
|---|---|---|
| Macro | `main(doc)` | once on menu pick; no UI [EX] |
| Tool | `buildUI(tool)`, button callbacks `fn(tool)` | params in Tool tab; undo helpers only valid here [DOC] |
| Polygonobj / Splineobj / Particle | `buildUI(obj)`, `buildObject(obj)` | core starts empty each rebuild; rebuild timing unpredictable |
| Tag | `buildUI(tag)`, `performExpression(tag)` | runs on scene evaluation only (time change, render, edit) — **not a clock; cannot poll** |

Header `//C3D_VERSION_REQUIREMENT 7.0.0` gates version. Long macros block the main thread and UI; throwing after `retainRedrawLock()` leaves UI frozen [FORUM].

## 2. Globals and classes
**Globals:** `print(str)`, `clearConsole()`, `version()`; undocumented `intToBinary floatToBinary binaryToInt binaryToFloat` [STR].

**OS [DOC]:** `beep()`, `messageBox(title,msg)` (1 OK/0), `runOpenPanel(ext...)`, `runSavePanel(ext)`, `system(cmd)` → Number. `system` is **synchronous**, passes string to `/bin/sh`, does **not** capture stdout (redirect to file) [FORUM/INF]; return value may be raw wait status (exit×256) **[INF — probe]**. Removed in 5.2, back in 8.x [STR/DOC]. App is **not sandboxed** (no entitlements).

**File [DOC]:** `new File(absPath)` (no `~` expansion). `open(READ_MODE|WRITE_MODE[,BIG_ENDIAN|LITTLE_ENDIAN])`, `close`, `isOpen`, `exist`, `isDir`, `size` (bytes), `extension`, `lastPathComponent`, `directory`, `contentOfDir`, `copyTo(path)`, `mkDir` (**manual: deletes any existing file/folder at path without warning → BANNED in this project**), `read(n)` (**n = characters, not bytes**), `readln`, `write`, `writeln`, binary `readShort/Int/UInt/Float` + `write*`, `seek(off,SEEK_SET|CUR|END)`, `getpos`, `setpos`. **No rename, no delete.**

**Document [DOC]:** `activeCamera()`, `redrawAll()`, `retainRedrawLock()/releaseRedrawLock()`, `setWindowFrame`, `editMode()`, `fileName()`, `root()`, `selectedObject()` (returns root if none [FORUM]), `selectedObjects(flat)`, `selectObject(obj,extend)`, `addObject(typeConst)`, `addMaterial(typeString,name)`, `materialAtIndex/Count`, `removeMaterial`, `render()`, `render(path)` (**synchronous**; format from extension; `.tiff` [EX], `.png` [WS]), `saveToFile(path,type)` (`"jas"` [WS]; `"obj"`,`"mtl"` [FORUM]; others [INF]), `rendererCount/AtIndex/currentRenderer/setCurrentRenderer`, takes: `addTake takeAtIndex takeWithName takeCount removeTake renameTake setCurrentTake currentTake`, time: `animPosition() setAnimPosition(t) animationEnd()`; undocumented [STR]: `animationTime() setAnimationTime() animationFPS() setAnimationFPS()`. **No open/import/new/close/clone API.**

**Base (all objects/tags/materials/nodes/tools/renderers) [DOC]:** UI-only (call in `buildUI`): `addParameterFloat/Int/Bool/Vec2D/Vec3D/Color(name,init,min,max,animate,build)`, `addParameterString`, `Texture`, `Link`, `Selector(name,[opts],animate,build)`, `Separator`, `Button(name,title,fnName)` (omitting trailing args can crash). Values: `getParameter(name[,time])`, `setParameter(name,value[,update])` (`"param.tex"` → Texture; unknown name throws). Introspection: `parameterCount/AtIndex/WithName`, `parameterInfo()` → `[[name,type],...]`. Identity: `document() owner() family() type() selection() script() scriptPath()`; nodes have `id()`; **scene objects have no stable id; names auto-uniquified (`Probe.2`) [WS]**. Hints: `modifiedHint() modifiedHint2Root() updateModifiedHint(h)`. Undo: `recordParametersForUndo() recordGeometryForUndo()` (**documented Tool-scripts-only**).
**Vector params print as `[object CallbackObject]` [WS]** → serialize via `parameterInfo()`/`Parameter.type()` + `.x .y .z .w` reads.

**Object [DOC]:** `childCount childAtIndex addChildAtIndex(child,i)(re-parents) removeChild`, `addTagOfType tagCount tagAtIndex tagOfType removeTag materialTags`, `core() modCore()`, `obj2WorldMatrix() objMatrix()`, `update()` (required after edits), `isCreatorObj/setCreatorObj`.
**Tag:** `linkedToMaterial()`, `tag2WorldMatrix()`, `update()`, skeleton `addCluster clusterAtIndex clusterCount removeClusterAtIndex`. Assign material: `addTagOfType(SHADERTAG).setParameter("material", mat)` [WS].
**Material:** `color colorMap emission reflection specular transmission shininess` (read-only), `rootNode nodeCount nodeAtIndex nodeWithID addNodeOfType(str) addConnection(fromID,fromPara,toID,toPara) removeConnection(id,para)`. Node types from `PlugIns/MaterialNodes/*`: shader (carpaint dielectric material membrane metal pbrmetal shadow solid toon velvet), textures (brick cellnoise checkerboard directional dots fractal image marble noise reptile turbulence voronoi wireframe wood), math (abs add cosine crossprod divide dotprod float2vec mix modulo multiply multiplyadd norm power pulse pulsetrain sine squareroot step subtract tangent vec2float), filter (composite gradient hsv2rgb rgb2hsv), constants (color number vector), other (instancestate state). `addMaterial("Material",name)` [WS]; others [INF].
**Node:** `frame() setFrame(Vec4D) nodeType() input/outputCount/AtIndex/WithName update()`. **Texture:** `width height filename pixel(x,y) sample(s,t)`. **Parameter:** `name type isAnimateable addTakeNode takeNodeCount/AtIndex/WithName connected connectedWithID connectedWithParameter`.
**Animation:** Take (`name length previewFrom previewTo`), TakeNode (`fCurveCount fCurveAtIndex name totalKeyCount`), FCurve (`addKey insertKeyAtIndex keyAtIndex(copy) keyCount removeKeyAtIndex removeAllKeys setKeyAtIndex valueAtTime update` — call `update()` after edits), FCurveKey (`new FCurveKey()`; `time value selected left_type left_time left_value right_type right_time right_value`; handles relative). Keyframing recipe [FORUM]: `parameterWithName → takeNodeWithName(take.name)||addTakeNode(take.name) → fCurveAtIndex(component) → addKey(new FCurveKey()) → update()`; times in seconds; `setAnimPosition`+`setParameter` does **not** create keys.
**PolyCore:** `addVertex(meshed,v) addPolygon(n[,meshed,Vec3D[],uv[]]) addIndexPolygon(n[,idx[],uv[]])` (**bad vertex index "could cause a crash"** → validate), `deleteVertex deletePolygon`, `vertexCount polygonCount triangleCount cornerCount`, `vertex(i) vertexIndex(p,c) polygonSize(p) uvCoord(p,c) normal(p[,c]) triangle(p,t) materialTagIndex(p)`, `setVertex setUVCoord flipWinding mergeVertices(tol)`, selections `vertexSelection polygonSelection edgeSelection(p,e,mask)` + setters, `setActivePolygonSelection(0..24)`, `buildVertexBSP/destroyVertexBSP`.
**SplineCore:** `move line curve(cp1,cp2,to) close currentPoint pathCount cache(i)`. **ParticleCore/Particle:** `addParticle particleCount particleAtIndex removeParticleAtIndex removeAllParticles`; per-particle Position/Speed/Rotation/Scale/UVW/Rand/Color/Weight/Birth/Death/Index/Visible. **Cluster:** `link linkBound linkSelection bindPose* transform* controlPointCount controlPointIndexArray controlPointWeightArray setControlPoints`.
**Math:** Vec2D/3D/4D (`add sub multiply norm copy set inverse isEqual`; Vec3D `dot cross convertEuler(from,to[,tip])`; aliases `.h .p .b .r .g .b .a .u .v`), Mat3D/Mat4D (`new Mat4D(TRANSLATE|SCALE|ROTATE|ROTATE_HPB,x,y,z)`, angles in degrees; `adjoint concat copy determinant inverse multiply transpose`; fields `m00..m33`).

## 3. Constants
Families: `OTHERFAMILY SPLINEFAMILY LIGHTFAMILY MODIFIERFAMILY NGONFAMILY TAGFAMILY LOADERFAMILY PARTICLEFAMILY MATERIALFAMILY NODEFAMILY SETTINGFAMILY FORCEFAMILY EFFECTORFAMILY`.
`addObject` types [DOC]: polygon `BALL BOX DISC CONE CAPSULE CYLINDER FRACTAL PLANE POLYGONOBJ POLYHEDRA TORUS TUBE SCRIPTPOLY STAIR`; spline `CIRCLE COG FLOWER HELIX LINE NEDGE RECT SCRIPTSPLINE SPLINE STAR TEXT`; scene `BLUEPRINT CAMERA FOLDER`; creators `BOOLEAN CHAIN EXTRUDE ISOSURFACE LATHE POLYPLANE RELIEF SUBDIV SWEEP SYMMETRY`; modifiers `*MOD`; particles `PARTICLE PARTICLEEMITTER PARTICLEARRAY PARTICLEMESH PARTICLESPLINE PARTICLESCRIPT`; `ORIENTATIONEFF`, `*FORCE`, `MATERIAL`. **Lights:** documented `POINTLIGHT/SPOTLIGHT/...` do not reliably exist; use `LIGHT` (=5) + Int parameter `lightType` [EX/WS]. Also [STR]: `SKYLIGHT ENVIRONMENTLIGHT JOINT SMARTFOLDER LOFT BACKGROUND SUBDIVMOD TRIANGULATEMOD WIREFRAMEMOD`.
→ **The runtime must build the real type map with `typeof X !== 'undefined'` at runtime (`capabilities` op); never trust the manual's list.**
Tags: `ANCHORTAG BAKETAG IKHANDLETAG IKCONSTRAINTTAG METABALLTAG MODETAG MORPHTAG ORIENTCONSTRAINTTAG PARENTCONSTRAINTTAG PARTICLETAG POINTCONSTRAINTTAG POSETAG PROPWINTAG RIGIDBODYTAG ROPETAG SKELETONTAG SOFTBODYTAG SPLINEIKTAG UVTAG SCRIPTTAG SHADERTAG` + [STR] `FOGTAG RADIOSITYTAG HDRITAG DOFTAG RENDERTAG CAUSTICTAG SPLINETRACKINGTAG TARGETTAG`.
Others: edit modes `POINT_MODE EDGE_MODE POLY_MODE OBJECT_MODE PIVOT_MODE`; hints `MODIFIED_NOTHING/TRANSFORM/PARAMETER/GEOMETRY/MODI/PARTICLE/TIME`; selection `EMPTY/PRIMARY/SECONDARY_SELECTION`; interpolation `LINEAR SOFT SPLINE FLAT CONST _INTERPOL`; param types `*_PARAMETER` (INT FLOAT BOOL STRING VEC2D VEC3D VEC4D TEXTURE LINK GRADIENT FLOAT_ARRAY); rotation orders `ROT_XYZ..ROT_HPB`; edge masks `SELECT UVPOINT UVEDGE UVPINNED SEAM CREASE NORMALBREAKBIT`; renderers `CHEETAH FALCON`; matrix `IDENDITY(sic) TRANSLATE SCALE ROTATE ROTATE_HPB`; file `READ_MODE WRITE_MODE BIG_ENDIAN LITTLE_ENDIAN SEEK_*`.

## 4. Rendering / saving / animation / undo
- `doc.render(path)` synchronous, no progress, no completion callback; resolution via `doc.currentRenderer().setParameter("resolution", new Vec2D(w,h))` (7.0+) [FORUM]; renderer params include `resolution gamma giOn` [WS]. No animation/movie API → loop `setAnimPosition` + `render(path)`.
- Render History: `~/Library/Application Support/Cheetah3D/Render History/<timestamp>/image.png` [FORUM #14373, observed on this Mac].
- Save: `saveToFile(path,"jas")` [WS]; **must probe whether it re-points the document (Save-As semantics)**.
- Undo: macro edits likely not undoable [INF]; strategy is file-based checkpoints.

## 5. Limitations (hard)
No networking/require/modules/timers/events; `eval` works (use indirect `var geval=eval; geval(src)` for globals; read file + eval is the module system) [WS/FORUM]; JSON.parse works [WS: build_cheetah.js]; macros block UI; no launch-time scripts, no CLI args, no URL scheme, no Services, **no AppleScript dictionary** (Info.plist has no `NSAppleScriptEnabled`, no `.sdef`); scripts can't react to selection events; no vertex-color API; no clone/make-editable/import/close from JS.

## 6. Menu commands reachable only via Accessibility (from MainMenu.nib)
Clone, Import File (`importFile:`), Merge, Make editable, Convert to, Undo (`undo:`), Save As/To (`saveDocumentAs:`/`saveDocumentTo:`), New (`newDocument:`), Render, RenderAnim, Show Render Manager. Captured top-level menus: `research/raw/menus_top_level.txt`.
