## Probe results (M0)
- **P02 (partial, 2026-10-29):** RESULT: a newly added macro (both in new subfolder `Macro/C3D-MCP-Probes/` and as top-level `Macro/zz-c3dmcp-probe-top.js`) did NOT appear in Tools › Script › Macro Script after ≥2 s and after activating the app. No "Update Menu" item is exposed in any menu (the `ScriptMenuUpdate` string lives only in Localizable.strings; AX walk of the window found no such control). Conclusion pending restart test: install requires a Cheetah3D restart. Evidence: AX menu listing via `osascript` (6 original macros only).
- **M0 step 0:** two "Untitled" windows pre-existing; AX exposes no AXEdited flag; user confirmed they are disposable. `UserFile.jas` sha256 == baseline (the baseline checksum).
- **P01:** RESULT: AX press of `Tools › Script › Macro Script › C3D-MCP-Probes › <file>` runs the macro **only while Cheetah3D is the active (frontmost) app**. When another app is frontmost the menu item reports `AXEnabled=0` and both System Events `click` and `AXUIElementPerformAction(kAXPress)` silently do nothing (press returns success, macro not run; not queued). A key document window is required. DESIGN AMENDMENT: helper must `activate` Cheetah3D, wait for `AXEnabled==1`, press, then restore the previously frontmost app. Subfolders produce submenus; macro `fileName()` of untitled doc is `undefined` (not null). Evidence: scripts/probes/run.sh experiments.
- **P02 (final):** RESULT: restart REQUIRED for new macros/folders (confirmed: after user restart the new folder + top-level file appeared). Edits to already-listed macro files are picked up on next run (loader macro P00 re-written without restart). No "Update Menu" control exists in menus.
- **P03/P36:** RESULT: 200 `File` writes = 11 ms; `contentOfDir` of 209 entries = 1 ms; 2,000 `addObject(BOX)` under a redraw lock = ~1 s; tree walk of 2,003 objects = 1 ms; removing 2,000 = ~1.2 s. File I/O is not the bottleneck; drain cap N=25 requests / T=8 s kept as initial values (no beachball observed ≤ 1.2 s; longer durations not measured). 
- **P04:** RESULT: `OS.system` is synchronous and returns the raw wait status (`exit 3` → 768 = exit×256; `exit 0` → 0). No stdout capture; redirect to a file works (`echo hi > "path with space/x"`); `cmd &` returns immediately; `sleep 1` blocks 1006 ms.
- **P05:** RESULT: `JSON.stringify/parse` fine incl. nested numbers; `JSON.stringify` does NOT escape non-ASCII. **`File.write(str)` with non-ASCII truncates the output** (writes only `str.length` bytes of the UTF-8 encoding) and `File.read(n)` decodes each *byte* as one char (Latin-1 mojibake: `名前` → `å\u0090\u008d…`). ⇒ ASCII-only `\uXXXX` escaping both ways is mandatory (confirmed). `JSON.parse` of an escaped file yields correct code points.
- **P06/P34:** RESULT: `File.read(f.size())` returns all bytes (size is bytes, n counts bytes≙chars for ASCII). `contentOfDir()` returns an **array of bare names** (not paths), sorted lexicographically, **includes dotfiles and `*.tmp`** (filter by regex). `open(WRITE_MODE)` creates missing files and **truncates** existing ones. `size()` of a missing file = 0; `exist()` false; `open(READ_MODE)` of missing returns null (no throw). `~` is not expanded. `copyTo(path)` works. `readln` strips newline. `File.isDir()` true for dirs.
- **P35:** RESULT: `print()` works but Cheetah's Console cannot be read externally ⇒ `c3d_get_console` = bridge runtime log only (as designed).
- **ES features (P05 ext.):** RESULT: JSC supports modern JS (let/const/arrow/template/for-of/spread/destructuring/classes/Promise/Map/Set/Symbol/padStart/typed arrays/`globalThis`). Bridge code is still written ES5 per requirements style rule. `geval` is NOT a predefined global (use `var geval = eval; geval(src)` / `(0,eval)(src)`; indirect eval defines globals). `require`, `setTimeout` undefined; `console` is an object (not probed further). Constants missing at runtime: `SPOTLIGHT SKYLIGHT SUBDIVMOD UVTAG LINEAR SOFT FLAT CONST IDENTITY` (interpolation constants are `LINEAR_INTERPOL=1 SOFT_INTERPOL=0 SPLINE_INTERPOL=2 FLAT_INTERPOL=2 CONST_INTERPOL=3`; `POINTLIGHT=15` exists but `addObject(POINTLIGHT)` throws "Wrong number or type of arguments" — use `LIGHT` + `lightType` 0..4). Full constant map: `research/raw/probe_PA_files_env.json`.
