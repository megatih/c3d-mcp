## Group: docs

### c3d_search_api_docs

**Search Cheetah3D API docs** - read-only, idempotent. Profiles: full, local, readonly.

Full-text (BM25) search over the Cheetah3D JavaScript API reference (per-method descriptions), the scripts bundled with the app, measured notes (verified in 8.1.3), gotchas/patterns, the book "Learn 3D with Cheetah 3D" and (last, only to fill free slots) archived forum threads. Use it BEFORE writing a script with c3d_run_script, or when unsure of a method signature, constant or known crash. Each hit has a trust level (official, verified, example, kb, book, book-unreviewed, forum) and, where the claim was tested in 8.1.3, a note saying whether it was confirmed, refined or refuted: prefer official/verified/example, treat kb/book-unreviewed/forum as hints to test. Query with identifiers or short phrases, e.g. "addIndexPolygon", "FCurve keyframe", "retainRedrawLock".

Local profile hint: _Search the Cheetah3D API docs for a method, constant or gotcha._

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string (len<=200) | yes | Search terms: API names, class.method or a short phrase. |
| `limit` | integer (>=1, <=10) | no | Max results (default 5). |
| `sources` | `official` \| `verified` \| `example` \| `kb` \| `book` \| `forum`[] | no | Restrict to these sources (default: all; forum threads only fill slots the others leave free). Use ["forum"] to search the archived forum alone. |

**Output fields:** `results` (object[]), `count` (integer (>=-9007199254740991, <=9007199254740991))

### c3d_open_document

**Open document** - writes. Profiles: full.

Opens a .jas scene or an importable model (obj, fbx, dae, stl, 3ds, usdz, dxf) in Cheetah3D as a NEW document window (open -a Cheetah3D) and binds the session to it. glb/gltf are NOT supported by Cheetah3D (convert to fbx/obj first). Imported models open as separate untitled-style documents, not merged into the current scene.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | Absolute path of the file to open. |

**Output fields:** `opened` (string), `window` (string), `document` (object)

### c3d_new_document

**New document** - writes. Profiles: full.

Creates a new empty untitled Cheetah3D document window (File > New via the helper) and binds the session to it with a hidden marker folder (__c3d_mcp_session_<uuid>, root level; ignore it in scene listings). Requires the helper (Accessibility permission).

No parameters.

**Output fields:** `window` (string), `document` (object)

### c3d_save_document

**Save document copy** - writes. Profiles: full, local.

Saves the scene as a .jas file via saveToFile. Copy semantics: the open document is NOT re-pointed to the new path and keeps its title/dirty state. Relative paths go to <workDir>/saves. Never overwrites a file that existed before this session; a file written earlier by this server needs confirmation. The target directory must exist unless it is inside the work directory.

Local profile hint: _Save a copy of the scene as a .jas file._

| Parameter | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | Target .jas path (absolute, or relative to the work directory). |
| `confirm` | boolean | no | Set true to confirm when the client cannot show a confirmation prompt. |

**Output fields:** `path` (string), `type` (string), `size` (number)

### c3d_export

**Export scene** - writes. Profiles: full.

Exports the scene to obj/fbx/dae/stl/3ds/usdz/gltf/glb/dxf (obj also writes a sibling .mtl). Other formats are not produced. Does not change the open document. Relative paths go to <workDir>/exports. Never overwrites files that predate the session (sibling .mtl included); missing directories are only created inside the work directory. WARNING: obj export crashed Cheetah3D 8.1.3 once on a scene with nested folders (probe notes, crash #1); prefer fbx/dae/stl/usdz/3ds/dxf. A checkpoint is taken automatically before an obj export.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | Target file; extension decides the format unless format is given. |
| `format` | `obj` \| `fbx` \| `dae` \| `stl` \| `3ds` \| `usdz` \| `gltf` \| `glb` \| `dxf` | no | Export format (default: from the extension). |
| `confirm` | boolean | no | Set true to confirm when the client cannot show a confirmation prompt. |

**Output fields:** `path` (string), `type` (string), `size` (number)

Reopens a checkpoint as a NEW Cheetah3D document window (the current window is not modified or closed - an extra window remains, close it manually if unwanted) and binds the session to the restored copy. Needs confirmation. Omit id for the latest checkpoint; with list_only:true just lists checkpoints.

| Parameter | Type | Required | Description |
|---|---|---|---|

| `list_only` | boolean | no | Only list checkpoints, do not restore. |

**Output fields:** `checkpoints` (object[]), `restored` (object), `window` (string)

### c3d_use_document

**Select working document** - writes, idempotent. Profiles: full.

Chooses which open Cheetah3D document later tools act on: raises the window with the given title (helper) and binds the session to its file name, or to a hidden session marker folder for untitled documents. Use after c3d_open_document/c3d_new_document/restore/import (they call it automatically) or when the user has several windows open. ### c3d_create_object

**Create object** - writes. Profiles: full, local.

### c3d_look_at

**Look at target** - writes, idempotent. Profiles: full, local.

Rotates an object (typically a camera or light) so its forward axis (-Z by default) points at a target object or world point. Computes HPB rotation in TypeScript, accounts for the parent rotation, applies it, then re-reads the world matrix and reports residual_deg (should be ~0). Give exactly one of target_ref / target_point. If residual_deg is large, try forward:"+z".

Local profile hint: _Aim a camera/light/object at a target object or point._

| Parameter | Type | Required | Description |
|---|---|---|---|
| `ref` | integer (>=-9007199254740991, <=9007199254740991) \| string \| object | yes | Object to rotate. |
| `target_ref` | integer (>=-9007199254740991, <=9007199254740991) \| string \| object | no | Look at this object (its world position). |
| `target_point` | any[] \| object | no | Look at this world point. |

### c3d_create_mesh
